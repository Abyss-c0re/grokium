# Grokium themes

Default: **Crimson Cube OS** — black lattice, blood crimson, gold edge.

## TUI
```
/theme              # list
/theme crimson      # ★ default — Cube portal energy
/theme matrix       # SMX green rain
/theme void         # station cyan
/theme gold         # Commander amber
/theme mono         # teletype
```
Persists: `data/ui_theme.json`

## Web (optional)
Header dropdown; same ids; localStorage.
